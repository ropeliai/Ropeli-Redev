# Ropeli AI — App Builder

AI-powered app builder that generates React Native (Expo) and React web apps from natural language prompts.

## Structure

- `ropeli-frontend/` — React + Vite frontend with Monaco editor and Sandpack live preview
- `ropeli-backend/` — Node.js + Express backend with OpenAI/Modal AI code generation and Expo runner

## Getting Started

### Backend
```bash
cd ropeli-backend
npm install
node server.js
```

### Frontend
```bash
cd ropeli-frontend
npm install
npm run dev
```
